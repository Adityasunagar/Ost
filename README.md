# Ost
A simple and responsive personal portfolio template built using HTML, CSS, and Bootstrap 5. It includes a navigation bar, a visually appealing hero section with a gradient background, and an "About Me" section. This template is perfect for beginners looking to create a clean and modern portfolio website with minimal setup.

Features:
Responsive navigation bar using Bootstrap

Hero section with gradient background and call-to-action

Clean layout for personal introduction

Fully responsive and mobile-friendly design
